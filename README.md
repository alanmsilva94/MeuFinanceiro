# MeuFinanceiro

**Versão 1.8.0** · Aplicativo local para organizar finanças pessoais, com suporte a uma pasta de dados compartilhada na rede.

O MeuFinanceiro reúne contas, receitas, despesas, cartões e investimentos em uma interface simples. Funciona sem internet; fontes e ícones estão incluídos no projeto.

## Começar

1. Baixe ou clone este repositório e extraia a pasta do projeto em um local fixo.
2. Abra index.html no Google Chrome ou no Microsoft Edge.
3. Escolha uma pasta para armazenar os dados e permita a edição quando o navegador solicitar.

> Os dados ficam na pasta escolhida, separados dos arquivos do programa. Para usar em mais de um computador, escolha uma pasta de rede compartilhada e siga as orientações do guia.

## Recursos

- Contas, transferências, receitas, despesas e lançamentos recorrentes.
- Cartões, compras parceladas, faturas e pagamentos.
- Investimentos, aportes, resgates, rendimentos e taxas.
- Painel financeiro, gráficos e evolução do patrimônio.
- Backups, restauração, exportação para Excel e impressão em PDF.

## Proteja seus dados

Faça backups periódicos e guarde uma cópia fora da pasta de dados. O backup automático dentro dessa pasta ajuda a recuperar alterações, mas não protege contra a perda da pasta inteira.
